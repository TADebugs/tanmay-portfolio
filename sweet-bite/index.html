Facts

  • Four pages: home, menu, reservations, about us.
  • The reservation form takes name, time, table type, email and phone, validates in the browser and confirms with an alert. There is no backend; nothing is sent.
  • Plain HTML, CSS and JavaScript, no build step. Chart.js draws the one chart on the about page.
